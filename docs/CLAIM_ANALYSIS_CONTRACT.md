# Claim analysis contract

Версия промпта: `misinfo-review-v2`.

Этот контракт подготавливает RuFact к анализу текста по отдельным утверждениям. Gemini по-прежнему работает без поиска в интернете, поэтому ни одна категория не означает, что факт подтверждён внешним источником.

## Формат

Полный Gemini-ответ содержит массив `claims` из одного–шести элементов:

```json
{
  "id": "claim-1",
  "quote": "Учёные всё доказали",
  "kind": "FACTUAL",
  "assessment": "UNSUPPORTED",
  "explanation": "В тексте нет проверяемого первоисточника.",
  "needsExternalVerification": true
}
```

`id` и `needsExternalVerification` вычисляет сервер. Gemini возвращает только `quote`, `kind`, `assessment` и `explanation`.

## Семантика

### `kind`

- `FACTUAL` — утверждение, которое в принципе можно проверить по внешним данным.
- `OPINION` — мнение, оценка или субъективное суждение.

### `assessment`

- `PLAUSIBLE` — выглядит правдоподобно по содержанию текста, но не проверено.
- `SUSPICIOUS` — содержит логические или языковые признаки риска.
- `UNSUPPORTED` — заявлено без достаточной опоры в самом тексте.
- `UNSURE` — данных недостаточно даже для осторожной оценки.
- `NOT_APPLICABLE` — применяется только к `OPINION`, поскольку мнение не получает фактологический вердикт.

## Инварианты безопасности

- `quote` должна быть точной непрерывной подстрокой исходного текста.
- Для `FACTUAL` значение `needsExternalVerification` всегда `true`.
- Для `OPINION` допустим только `NOT_APPLICABLE`, а `needsExternalVerification` всегда `false`.
- Не более шести утверждений; объяснение не длиннее 500 символов.
- Лишние поля, выдуманные цитаты и несовместимые категории отклоняют весь Gemini-ответ.
- `externalSourcesChecked` остаётся `false` для всего ответа.

Этот формат позволяет на следующем этапе безопасно подсвечивать точные цитаты и показывать отдельные карточки утверждений, не создавая ложного впечатления полноценного фактчекинга.
