# RuFact

Полированный MVP интерфейса для вероятностной проверки русскоязычных текстов на признаки недостоверной информации.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверки

```bash
npm run typecheck
npm run lint
npm run build
```

Клиентская интеграция анализа изолирована в `lib/api.ts`. По умолчанию интерфейс обращается к демонстрационному `POST /api/analyze`; адрес можно заменить через `NEXT_PUBLIC_ANALYSIS_API_URL`.

Локальный ответ всегда помечается как `demo-heuristic`. Если задан внешний FastAPI endpoint и он недоступен, интерфейс показывает ошибку вместо скрытой подмены результата демонстрационным классификатором.

Процент в карточке результата — уверенность в конкретной классификации, а не измеренная accuracy. Метрики качества в интерфейсе остаются в состоянии «Не измерено» до оценки реальной модели на отдельной размеченной выборке.
